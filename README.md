##  Projects

<div align="center">

### Autonomous Vacuum Cleaning Robot
**Flagship Project**

</div>

An industrial-style autonomous cleaning robot built on **ROS2 Jazzy**, controlled entirely from a browser-based dashboard.

**Technologies:** `ROS2 Jazzy` `Nav2` `SLAM Toolbox` `AMCL` `React.js` `WebSockets` `Regulated Pure Pursuit` `Behavior Trees`

**Highlights:**
- Three path modes — Point-to-Point, Freehand Drawing, and Zone Cleaning (automatic zigzag coverage)
- Live React web dashboard over WebSockets with real-time robot position and battery monitoring
- Battery drain simulation with auto-docking and automatic charging
- Pause, resume, and emergency stop controls
- Obstacle recovery with AMCL localization and SLAM Toolbox mapping
- Adjustable path resolution and row spacing for coverage planning
- Fully browser-controlled — no terminal required for operation

### French Café Butler Robot

</div>

An autonomous café delivery robot simulated in **Gazebo Harmonic**, driven by a finite state machine for reliable multi-order service.

**Technologies:** `ROS2 Jazzy` `Gazebo Harmonic` `Nav2` `Finite State Machine`

**Highlights:**
- Autonomous navigation between kitchen and table zones
- Kitchen and table confirmation checkpoints before each delivery
- Multiple order queue handling
- Safety cancellation and automatic return-home behavior
- Clean state machine design governing the full delivery lifecycle
